變數分類（內部稱為"資料"）包含兩種儲存方式：變數（每個儲存一個值）和列表（按順序儲存許多值）。您可以使用分類頂部的"建立一個變數"和"建立一個列表"按鈕建立變數和列表；Bilup 還有一個專門的[變數管理器](/editor/variable-manager)用於批次編輯。

變數或列表可以是**適用於所有角色**的（全域）或**僅適用於當前角色**的（限於一個角色及其克隆體）。

## 變數

- **`變數`**（報告積木）報告變數的當前值。在積木區勾選它的核取方塊會在[舞臺](/editor/stage)上顯示監視器。
- **將 `變數` 設為 `0`** 儲存一個值。
- **將 `變數` 增加 `1`** 向數字變數加上一個數字。
- **顯示變數 `變數`** / **隱藏變數 `變數`** 顯示或隱藏舞臺監視器。

## 列表

- **`列表`**（報告積木）報告列表的內容。
- **將 `東西` 加入 `列表`** 在末尾追加一項。
- **刪除 `列表` 的第 `1` 項** 按位置移除一項（選單還提供 `最後一項` 和 `全部`）。
- **刪除 `列表` 的全部專案** 清空列表。
- **將 `東西` 插入 `列表` 的第 `1` 項** 在某個位置新增一項，將其餘項下移。
- **將 `列表` 的第 `1` 項替換為 `東西`** 覆蓋一項。
- **`列表` 的第 `1` 項** 返回某個位置的專案。
- **`東西` 在 `列表` 中的專案編號** 返回一項的位置，如果未找到則為 0。
- **`列表` 的專案數** 返回列表包含多少項。
- **`列表` 包含 `東西` ?** 報告列表是否包含某個專案。
- **顯示列表 `列表`** / **隱藏列表 `列表`** 在舞臺上顯示或隱藏列表監視器。

## Bilup 和 TurboWarp 額外積木

- **`列表` 的 JSON 表示**（`data_listjson`）將整個列表報告為 JSON 陣列字串，便於以文本形式儲存或傳送列表資料。
