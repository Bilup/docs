偵測積木讀取腳本週圍的世界：碰撞、滑鼠和鍵盤、計時器、日期以及其他角色的屬性。

## 碰到與距離

- **碰到 `滑鼠指標` / 邊緣 / 角色 ?** 報告角色是否碰到目標。
- **碰到顏色 `[#顏色]` ?** 報告角色是否碰到螢幕上的某種顏色。
- **顏色 `[#顏色]` 碰到 `[#顏色]` ?** 報告角色上的一種顏色是否碰到另一種顏色。
- **到 `滑鼠指標` / 角色的距離** 報告以畫素為單位的距離。

## 詢問與回答

- **詢問 `你叫什麼名字?` 並等待** 顯示輸入框並暫停直到使用者回答。
- **回答** 報告最近一次的回答。

## 滑鼠與鍵盤

- **滑鼠按下?** 報告滑鼠按鈕是否被按住。
- **滑鼠的 x 座標** / **滑鼠的 y 座標** 報告指標的位置。
- **按下 `空格` 鍵?** 報告某個鍵是否被按住。
- **將拖動模式設為 `可拖動` / `不可拖動`** 控制播放者是否可以拖動此角色。

## 值與屬性

- **響度** 報告麥克風輸入電平（0 到 100）。
- **計時器** 報告自計時器上次重置以來的秒數；**計時器歸零** 將其設定為零。
- **`背景編號` 屬於 `舞臺` / 角色的屬性** 報告其他角色或舞臺的屬性（x、y、方向、造型、大小、音量、變數等）。
- **當前時間的 `年` / `月` / `日` / `星期` / `小時` / `分鐘` / `秒`** 報告當前日期和時間的一部分。
- **自 2000 年以來的天數** 報告自 2000 年以來的天數（帶小數）。
- **使用者名稱** 在可用時報告已登入播放者的使用者名稱。

## Bilup 和 TurboWarp 額外積木

- **線上?** 這個 `sensing_online` 布林積木報告裝置當前是否有網路連線（`navigator.onLine`）。
- **舞臺寬度**（`sensing_stagewidth`）報告以畫素為單位的舞臺寬度（預設為 480，但[舞臺大小](/editor/stage)可以更改）。
- **舞臺高度**（`sensing_stageheight`）報告以畫素為單位的舞臺高度（預設為 360）。

還有一個由 `當 ... >` 帽子積木使用的 **響度 > `10`?** 風格布林積木。

請參閱[Bilup 額外積木](/blocks/bilup-extras)。
