Bilup 建構在 TurboWarp 之上，而 TurboWarp 建構在 Scratch 之上。一路走來，兩個專案都添加了標準 Scratch 沒有的積木。本頁將這些額外積木集中在一處。每一個都位於其正常分類中，並從該分類的頁面連結到。擴充功能積木（畫筆、音樂等）請參閱[擴充功能](/extensions/overview)；本頁只涉及內建額外積木。

其中一些積木預設顯示在積木區中；其他是來自匯入專案或開啟相應外掛才會出現的相容性或進階積木。它們在[編譯器](/advanced/disable-compiler)和直譯器中都以相同方式執行。

## 運動

- **面向 x: `0` y: `0`** 朝向特定座標，而不是選單目標。
- **從 x: `0` y: `0` 面向 x: `0` y: `0`** 從一個座標朝向另一個座標。

請參閱[運動積木](/blocks/motion)。

## 控制

- **重複執行直到 `<條件>`** 在布林值保持為真時迴圈（`重複執行直到` 的反義詞）。
- **對於 `10` 中的每個 `專案`** 迴圈設定次數，將變數設定為 1、2、3，依此類推。
- **全部同時** 在一幀內以無螢幕重新整理讓步的方式執行其包裹的積木。為相容舊專案而保留；[防卡死](/advanced/warp-timer)下的普通指令碼行為相同。
- **切換 `表示式`** / **情況 `值`** / **預設** / **中斷** 建置 switch 語句。`切換` 透過匹配值選擇一個分支；普通的 `情況` 執行其分支然後停止；`預設` 在沒有匹配時執行；`中斷` 和 case 穿透控制讓一個 case 繼續到下一個。
- **計數器**（報告積木）、**計數器增加**、**將計數器設為 `0`** 是從 Scratch 2 繼承的簡單內建計數器，因此您無需建立變數即可計數。

請參閱[控制積木](/blocks/control)。

## 運算

- **`蘋果` 的第 `1` 到 `3` 個字元** 返回兩個位置之間的子字串。
- **`蘋果` 中 `專案` 的位置** 返回子字串的位置（不區分大小寫），如果未找到則為 0。
- **將 `蘋果` 中的 `a` 替換為 `-`** 替換子字串的每次出現（不區分大小寫）。
- **`ab` 重複 `3` 次** 重複一個字串。
- **將 `Apple` 轉為 `大寫` / `小寫`** 更改文本的大小寫。
- **修剪 `  蘋果  `** 移除周圍空白。
- **將 `5` 限制在 `0` 和 `10` 之間** 將數字限制在一個範圍內。
- **較小值** / **較大值** 返回運算元中較小或較大的值。
- **圓周率** 報告 3.14159...
- **換行符** 報告換行字元。

請參閱[運算積木](/blocks/operators)。

## 偵測

- **線上?** 報告裝置是否有網路連線（`navigator.onLine`）。
- **舞臺寬度** / **舞臺高度** 報告以畫素為單位的舞臺大小。

請參閱[偵測積木](/blocks/sensing)。

## 變數和資料

- **`列表` 的 JSON 表示** 將列表報告為 JSON 陣列字串。

請參閱[變數和列表](/blocks/variables)。

## 自制積木

- **返回 `值`** 結束自訂積木並將值交還給呼叫者，讓自訂積木充當報告積木。
- **已編譯?** / **是 bilup?** 是特殊的布林引數報告積木名稱：`已編譯?` 在編譯器執行時報告真，`是 bilup?` 在這裡始終報告真。

請參閱[自制積木](/blocks/my-blocks)。
