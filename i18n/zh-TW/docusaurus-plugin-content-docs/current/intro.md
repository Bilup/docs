# Bilup 文件

[Bilup](https://com.bilup.org/) 是一個基於 TurboWarp 的 Scratch 修改版。它保留了您熟悉的 Scratch 編輯器，並添加了一個將積木編譯為 JavaScript 的編譯器、大量外掛與主題、專案打包器、偵錯器、git 版本控制、即時協作，以及完整的社群平臺與帳戶系統。

編輯器和社群站點由同一個建置提供。您可以直接在瀏覽器中造訪 [com.bilup.org](https://com.bilup.org/)，無需帳戶、無需安裝即可使用 Bilup。當您想發佈專案、關注他人並在裝置間同步設定時，可以使用 Bilup Accounts 帳戶登入。
