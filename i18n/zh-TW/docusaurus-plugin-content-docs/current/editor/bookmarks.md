工作區書籤儲存積木[工作區](/editor/workspace)中的一個位置，這樣您可以立即跳回它。書籤記錄您正在看的位置（哪個角色、縮放級別和滾動位置），這比滾動查詢指令碼更快地在大型專案中移動。

## 書籤選單

書籤透過[選單欄](/editor/menu-bar)中的**書籤**選單管理。它包含一個搜尋框、一個**添加當前位置**專案、書籤列表，以及底部的匯出 / 匯入 / 全部清除。每個書籤行顯示其名稱和儲存日期，帶有重新命名（鉛筆）和刪除（垃圾桶）按鈕。

## 新增和使用書籤

- **新增**：選擇**添加當前位置**，或按 `Ctrl+Alt+T`。這會在一個名稱下儲存當前角色、縮放和滾動位置。
- **切換**：點選書籤返回恰好該檢視。編輯器選擇儲存的角色並恢復其縮放和滾動偏移。
- **快速鍵**：`Ctrl+Alt+1` 到 `Ctrl+Alt+9` 切換到前九個書籤；`Ctrl+Alt+0` 切換到第十個。

## 分類

書籤可以分組到**分類**中（預設為"常規"）。分類標題可以摺疊和展開，這在專案有很多書籤時保持列表可管理。

## 匯出、匯入和儲存

- **匯出**將您的書籤下載為 JSON 檔案；**匯入**將檔案合併回來，不會建立重複項。
- 書籤**儲存在專案內部**，因此它們隨 `.sb3` 旅行，並在專案重新載入時重新出現。它們是按專案的。
