Bilup 為常見編輯器操作提供鍵盤快速鍵，並且它們可以重新繫結。顯示為 `Ctrl` 的快速鍵在 Windows 和 Linux 上使用 `Ctrl`，在 macOS 上使用 `⌘`（Command）。

## 預設快速鍵

**檔案**

| 操作 | 快速鍵 |
| --- | --- |
| 儲存 | `Ctrl+S` |
| 另存為副本 | `Ctrl+Shift+S` |
| 從電腦載入 | `Ctrl+O` |
| 打包專案 | `Ctrl+P` |
| 還原點 | `Ctrl+Shift+P` |

**編輯**

| 操作 | 快速鍵 |
| --- | --- |
| 撤銷 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` |
| 複製 | `Ctrl+C` |
| 貼上 | `Ctrl+V` |
| 剪下 | `Ctrl+X` |

**檢視**

| 操作 | 快速鍵 |
| --- | --- |
| 設定 | `Ctrl+,` |
| 切換全屏 | `F11` |
| 切換背包 | `Ctrl+Shift+B` |
| 切換舞臺全屏 | `Ctrl+Shift+F` |

**專案控制**

| 操作 | 快速鍵 |
| --- | --- |
| 啟動專案（綠旗） | `Ctrl+Enter` |
| 停止全部 | `Ctrl+Shift+Enter` |

**編輯器導航**

| 操作 | 快速鍵 |
| --- | --- |
| 聚光搜尋 | `Ctrl+K` |
| 程式碼標籤頁 | `Ctrl+1` |
| 造型標籤頁 | `Ctrl+2` |
| 聲音標籤頁 | `Ctrl+3` |

**素材庫**

| 操作 | 快速鍵 |
| --- | --- |
| 角色庫 | `Ctrl+Shift+A` |
| 造型庫 | `Ctrl+Shift+C` |
| 聲音庫 | `Ctrl+Shift+M` |
| 擴充功能庫 | `Ctrl+.` |
| 擴充功能管理器 | `Ctrl+Shift+E` |

**角色和視窗**

| 操作 | 快速鍵 |
| --- | --- |
| 複製角色 | `Ctrl+Shift+D` |
| 刪除角色 | `Ctrl+Shift+X` |
| 關閉視窗 | `Ctrl+Shift+K` |

一些功能有自己的按鍵，不在此管理器中，例如[查詢欄](/editor/find-bar)（`Ctrl+F`）、[書籤](/editor/bookmarks)（`Ctrl+Alt+T` 和 `Ctrl+Alt+1` 到 `0`）、[變數管理器](/editor/variable-manager)（`Ctrl+Shift+V`）和暫停（`Alt+X`）。

## 快速鍵管理器

開啟**設定**並轉到**鍵盤快速鍵**頁面。它列出每個可重新繫結的快速鍵，按分類分組，並帶搜尋框。

- 要更改一個，點選它的**鉛筆**按鈕，然後按新的組合鍵。`Escape` 取消。如果組合已被使用，管理器會告訴您哪個操作持有它並拒絕衝突。
- 更改過的快速鍵顯示**重置為預設值**按鈕，一旦您有任何自訂繫結，**全部重置為預設值**按鈕就會出現。

您的自訂繫結儲存到瀏覽器中，並在登入時同步到您的帳戶，因此它們跟隨您跨裝置。
