title: 自制積木（我的積木）

自制積木讓您為一段指令碼命名，並將其作為單個積木複用。它們位於[積木區](/editor/blocks-palette)的**我的積木**分類中。自制積木像一個函式：定義一次，然後在角色的任何地方呼叫它。

## 建立一個積木

1. 開啟**我的積木**並點選**建立一個積木**。
2. 在開啟的編輯器中，輸入積木的文本。邊進行邊點選按鈕新增輸入和標籤：
   - **新增輸入（數字或文本）**：接受任何值的凹槽，作為報告積木傳入定義。
   - **新增輸入（布林值）**：接受真/假條件的六邊形凹槽。
   - **新增標籤**：輸入之間的純文本，使積木讀起來像一句話（例如 `移動` `[步數]` `以速度` `[速度]`）。
3. 可選勾選**執行時不重新整理螢幕**（見下文）。
4. 點選**確定**。

您會得到兩樣東西：工作區中的一個**定義**帽子積木，以及積木區中的一個新積木。將您想複用的指令碼放在定義帽子下方。您新增的任何輸入都會作為報告積木出現在定義帽子上，您可以將其放入該指令碼。

## 執行時不重新整理螢幕

預設情況下，自制積木會像其他指令碼一樣在步驟之間重繪舞臺。**執行時不重新整理螢幕**使整個積木在一幀內完成，不暫停重繪。這是讓快速輔助程式（繪製、列表處理、數學）立即執行而不是每幀一次迴圈迭代的標準方式。要小心此類積木內的長或無限迴圈：它們可能凍結專案。Bilup 的[防卡死計時器](/advanced/warp-timer)設定可以防範許多此類凍結。

## 編輯和刪除

右鍵單擊**定義**帽子積木來編輯積木的輸入，或右鍵單擊積木區中的積木來刪除它（當自制積木仍在指令碼中使用時不能刪除）。自制積木屬於定義它們的角色；複製或匯出角色會一併攜帶它們。

## 報告和布林自制積木

標準 Scratch 的自制積木只是命令（它們執行，但不報告值）。Bilup 添加了**自訂報告積木**，因此自制積木可以返回值：

- 右鍵單擊自制積木的定義帽子並選擇**更改為報告積木**（或**更改為命令**改回）。報告積木形狀的自制積木可以放入任何輸入，就像 `x 座標` 一樣。
- 在定義內部，使用**返回**積木交回一個值並停止積木。返回積木來自 Bilup 自動啟用的自訂報告積木功能。

這些積木是 Bilup 對 Scratch 的擴充功能。使用它們的專案在 scratch.mit.edu 上無法原樣執行。如果您需要標準相容性，**僅標準相容積木**[設定](/editor/settings)會隱藏它們。
