Bilup 的外觀是可主題化的：淺色或深色編輯器、強調色、積木的顏色，以及您可以建置和分享的完全自訂主題。本頁說明每一個都在哪裡。

## 編輯器主題和強調色

整體的**淺色或深色**外觀和**強調色**應用於整個 Bilup（編輯器和社群站點），因此它們位於您的 Bilup 帳戶設定中，而不是編輯器自己的視窗中。開啟[設定視窗](/editor/settings)，轉到**主題**頁面，然後按照**編輯我的 Bilup 設定**在站點上更改它們。

強調色分為純色、一組彩虹旗和更豐富的漸變強調色（如日落、海洋和極光）。您的選擇儲存到帳戶，並在登入時同步到您的裝置。

## 積木顏色

編輯器的**主題**頁面設定積木本身的配色方案，與介面主題分開：

- **原始**：標準 Scratch 積木顏色。
- **高對比度**：更醒目、更高對比度的顏色，提高可讀性。
- **深色（測試版）**：較深的積木顏色以匹配深色編輯器。

要更精細地控制各個分類顏色，**在外掛設定中自訂**會開啟積木主題外掛，每個分類的顏色都可以手動設定。

## 自訂主題

自訂主題將整體外觀（強調色、淺色或深色模式、積木顏色、桌布和字型）捆綁在一個名稱下，這樣您可以在它們之間切換或分享它們。自訂主題管理器讓您：

- **從當前外觀建立**：將您設定的所有內容快照到命名主題中。
- **建置漸變主題**：在漸變建置器中設計漸變強調色（見下文）。
- **匯入和匯出**：從 JSON 檔案載入主題，或將您的整個庫匯出為一個檔案。
- **瀏覽市場**：開啟 WarpTheme 社群主題集合並將主題新增到您的庫中。

每個儲存的主題都可以單獨應用、編輯、匯出或刪除。

## 漸變建置器

漸變建置器為自訂主題設計漸變強調色：

- **色標**：沿預覽條拖動色標重新定位，選擇每個色標的顏色，並新增或移除色標（兩個到八個）。
- **方向**：用滑塊或八個預設箭頭之一設定漸變角度。
- **快速預設**：從現成的漸變開始。
- **主色**：從漸變派生的純色，用於 UI 強調。

**預覽**即時應用漸變，這樣您可以在儲存前看到它，關閉預覽會恢復您之前的主題。

## 將主題與專案捆綁

專案可以攜帶自己的主題。儲存時，Bilup 可以將您當前的主題儲存在專案中（透過[設定](/editor/settings)常規頁面上的**將設定儲存到專案中**，並勾選**將主題儲存到專案中**）。當有人在編輯器中開啟該專案時，Bilup 會詢問是**應用**專案的主題還是**保留**他們自己的主題，並提供"不再詢問"選項。在專案的社群頁面上，儲存的主題會自動應用到播放器。
