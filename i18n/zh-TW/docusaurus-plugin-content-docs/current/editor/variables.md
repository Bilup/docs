# 變數和列表

變數儲存單個值（一個數字或一段文本）。列表按順序儲存許多值。兩者都位於積木區的**變數**分類中，並且都用該分類頂部的按鈕建立。

## 建立一個變數

1. 開啟[積木區](/editor/blocks-palette)中的**變數**分類。
2. 點選**建立一個變數**。
3. 輸入名稱並選擇作用域（見下文）。
4. 點選**確定**。

您的新變數會出現在積木區中，帶有 `設`、`增`、`顯示`和`隱藏`積木，以及一個可以放入任何輸入的報告積木。

列表以相同方式工作：改為點選**建立一個列表**。列表帶有新增、刪除、插入、替換和讀取專案以及檢查其長度和內容的積木。

## 作用域：所有角色 vs 當前角色

建立變數或列表時，您選擇兩個作用域之一：

- **適用於所有角色**（全域）：每個角色和舞臺共享同一個變數。從一個角色更改它，到處都會更改。用於分數或遊戲狀態等整個專案都關心的內容。
- **僅適用於當前角色**（區域性）：變數屬於當前選中的角色。其他角色看不到它，角色的每個克隆體都有自己的私有副本。用於健康值或速度等每個角色的資料。

舞臺只能持有全域變數，因為它沒有克隆體，也沒有"區域性"可以歸屬。

::::note
兩個角色可以各自擁有同名區域性變數而不衝突，因為它們確實是獨立的變數。區域性變數和全域變數也可以同名；在它的角色內，區域性變數優先。
::::

## 舞臺上的監視器

每個變數和列表都有一個**監視器**，即顯示在[舞臺](/editor/stage)上的小讀數。透過勾選積木區中變數旁邊的核取方塊來切換它，或使用 `顯示變數` / `隱藏變數` 積木。

- 將監視器拖到舞臺上的任何位置來重新定位它。
- 右鍵單擊變數監視器可在普通讀數、大讀數和可以拖動以即時更改值的滑塊之間切換。
- 右鍵單擊列表監視器可調整大小或匯出/匯入其內容。

監視器與專案一起儲存，因此它們的位置和樣式隨之旅行。

## 進階說明

- 變數和列表值儲存為 JavaScript 字串和數字。[編譯器](/advanced/disable-compiler)直接讀寫它們，因此大列表很快，但非常大的列表仍然消耗記憶體和儲存時間。
- 列表比較預設不區分大小寫。[設定](/editor/settings)中的**區分大小寫的列表**選項使 `"a"` 和 `"A"` 成為不同的值，這可以以標準相容性為代價加快列表密集型專案。
- 要一次檢視或批次編輯所有變數和列表，請使用[變數管理器](/editor/variable-manager)。
