即時協作讓幾個人同時即時編輯同一個專案。每個人都在自己的編輯器中工作，積木、角色、造型和聲音的更改在所有人之間同步，即時游標顯示誰在哪裡工作。

::::warning
即時協作是一個 alpha 功能，仍處於早期開發階段。在協作會話中編輯的專案可能被損壞或破壞。使用它時請保留自己的[還原點](/editor/restore-points)或儲存的副本。
::::

## 開始或加入會話

開啟**工具**選單並選擇**即時協作**。視窗顯示您將以什麼使用者名稱出現，以及兩個選項：

- **建立新房間**：主持一個房間。您會得到一個房間程式碼（以及可以分享的 URL），其他人用它加入。您是房間的**主持人**。
- **加入現有房間**：輸入房間程式碼加入別人主持的房間。

分享房間透過傳送它的 URL 完成，URL 攜帶一個 `?room=` 程式碼；開啟該連結會自動加入房間。

## 會話期間

連線後，視窗列出房間中的每個人。每個人顯示他們的頭像和名稱，在相關處顯示**主持人**或**您**徽章，以及他們在做什麼的即時描述，例如"正在編輯 Sprite1 中的程式碼"或"正在編輯舞臺中的造型"。在工作區中，您會看到其他人的**游標**帶名稱標籤，在他們移動時顯示。

**複製房間 URL 以分享**複製邀請連結，**離開房間**斷開您的連線。

## 主持人控制與隱私

建立房間的人是主持人，有額外控制：

- **踢出**任何其他參與者。
- 將房間設定為**公開**（任何有程式碼的人都可以加入）或**私有**（人們必須請求批准）。
- 在私有房間中，**批准或拒絕**每個待處理的加入請求。

當您加入私有房間時，您會等待主持人批准您，然後才能進入。

::::note
主持人轉發每個人的編輯，這意味著主持人可以看到加入者的 IP 地址，而在您建立的房間中，加入者可以看到您的。視窗中的隱私宣告在您主持或加入之前會說明這一點。
::::

## 協作與 git 的區別

即時協作用於在同一時刻一起編輯。對於非同步團隊合作（人們分別做更改，之後再合併），請改用[git 版本控制](/editor/git)。
