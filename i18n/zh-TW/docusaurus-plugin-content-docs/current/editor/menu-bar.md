選單欄橫跨編輯器頂部。它包含下拉式選單（檔案、編輯、工具、書籤）、設定按鈕、專案標題，右側是儲存狀態和帳戶。本頁列出每個選單和專案。

最左側的 **Bilup** 徽標是到主頁的連結。在窄視窗上，選單摺疊到 **更多**（☰）按鈕後面；專案完全相同。

下面顯示的鍵盤快速鍵在 Windows/Linux 上使用 `Ctrl`，在 macOS 上使用 `⌘`。完整列表在[鍵盤快速鍵](/editor/shortcuts)中。

## 檔案

- **新建** 建立全新專案。如果當前專案有未儲存的更改，會先警告您。
- **新視窗**（僅桌面應用）開啟第二個編輯器視窗。
- **立即儲存**（`Ctrl+S`）儲存到專案當前所在的位置。當您已登入且專案屬於您時，這會上傳到 Bilup。請參閱[專案管理](/editor/project-management)。
- **另存為副本**（`Ctrl+Shift+S`）儲存一個新的獨立副本。
- **改編** 基於當前專案開始一個新專案。
- **儲存到 Bilup** / **改編到 Bilup**（登入[Bilup Accounts 帳戶](/editor/project-management)後顯示）將專案上傳到您的帳戶。上傳本身從不發佈專案；分享是在網站上單獨進行的。
- **檢視專案頁面** 開啟此專案在社群站點上的頁面（專案存在於 Bilup 後顯示）。
- **從電腦載入**（`Ctrl+O`）從磁碟開啟 `.sb3` 檔案。
- **儲存到（檔名）** 和 **另存為...** 將 `.sb3` 儲存到您的電腦。在支援檔案系統存取 API 的瀏覽器上，您可以儲存回同一檔案；否則會正常下載。
- **打包專案**（`Ctrl+P`）在[打包器](/packager/overview)中開啟當前專案。
- **提交到 Git...**、**推送到（遠端）**、**從（遠端）拉取** 在專案有[Git 倉庫](/editor/git)時出現。
- **還原點**（`Alt+R`）開啟[還原點](/editor/restore-points)管理器；**建立還原點** 立即建立一個。
- **專案後設資料** 顯示開啟專案的作者、日期和內容。
- **暫停自動儲存** / **恢復自動儲存** 在自動儲存開啟時出現，並帶有到下次自動儲存的即時倒計時。

## 編輯

- **恢復角色 / 聲音 / 造型** 找回您最後刪除的內容（沒有可恢復內容時停用）。
- **撤銷**（`Ctrl+Z`）和**重做**（`Ctrl+Shift+Z`）作用於積木[工作區](/editor/workspace)。
- **外掛** 開啟[外掛設定](/editor/addons)。
- **桌面設定**（僅桌面應用）開啟應用級選項。
- **更改使用者名稱** 設定報告給專案和雲端變數的使用者名稱。
- **啟用 / 停用雲端變數** 為本次會話切換[雲端變數](/advanced/cloud-variables)（在不可用時停用）。
- **顯示教程** 重播入門演練。
- **幫助** 開啟編輯器內的幫助視窗，一個可搜尋的編輯器、積木和擴充功能參考。
- **originChats** 連結到 originChats 社群聊天。

## 模式

**模式**選單僅在編輯器偶爾出現的愚人節狀態期間顯示。它提供**普通模式**和**貓咪模式**（貓主題積木）。它對專案執行沒有影響，並且一年中其他時間都關閉。

## 工具

- **Git** 開啟[版本控制](/editor/git)視窗。
- **終端** 開啟一個 shell 視窗。
- **即時協作** 開啟[即時協作](/editor/collaboration)。
- **偵錯器**和**變數管理器** 在這些工具可用時出現，分別開啟[偵錯器](/editor/debugger)和[變數管理器](/editor/variable-manager)。
- **新增擴充功能**（`Ctrl+.`）開啟[擴充功能庫](/extensions/overview)以新增或匯入擴充功能。
- **管理擴充功能**（`Ctrl+Alt+E`）列出專案中已載入的擴充功能。

## 書籤

書籤選單管理[工作區書籤](/editor/bookmarks)：積木工作區中儲存的相機位置，讓您可以立即跳回指令碼。在這裡您可以新增、切換、重新命名、刪除、匯出、匯入和清除書籤，並將它們組織到分類中。書籤與專案一起儲存。

快速鍵：`Ctrl+Alt+T` 在當前位置新增書籤；`Ctrl+Alt+1` 到 `Ctrl+Alt+0` 切換到前十個書籤。

## 設定

**設定**按鈕開啟[設定視窗](/editor/settings)：主題、語言、編譯器和執行時選項、[自訂 FPS](/advanced/custom-fps)、[自訂舞臺大小](/advanced/custom-stage-size)等。

## 右側

選單欄右側的帳戶區域顯示：

- **儲存狀態**，反映專案是否有未儲存的更改。
- 會話進行中時的**即時協作**存在指示器。
- 到 Bilup 站點其餘部分的導航。
- 您的 **Bilup Accounts 帳戶**，或登入提示。登入啟用儲存到 Bilup、分享以及設定的雲同步。

一個**專案標題**欄位在您擁有該專案時位於中間。在專案頁面上，您可能還會看到瀏覽量計數器、**分享**按鈕、**改編**按鈕和**檢視社群**按鈕，具體取決於專案和您是否已登入。**反饋**連結始終可用。
