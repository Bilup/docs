title: 查詢欄

查詢欄是內置於編輯器標籤行（程式碼、造型和聲音標籤頁旁邊）的搜尋框。它將您直接跳轉到當前角色中的積木、變數、自制積木、造型或聲音，這比滾動瀏覽大型專案快得多。

## 開啟它

按 `Ctrl+F`（macOS 上是 `Cmd+F`）聚焦查詢欄，或點選它。在窄視窗上它摺疊為點選時展開的放大鏡圖示。查詢欄在程式碼、造型和聲音標籤頁上都可用。

## 它查詢什麼

在**程式碼**標籤頁上，輸入會過濾當前角色或舞臺中的匹配下拉框：

- 帽子積木：`當綠旗被點選`、`當收到`、廣播、克隆開始和其他事件帽子。
- 自制積木定義。
- 普通積木，按名稱或輸入中的文本匹配。
- 變數和列表（全域和每角色，相應標記）。

在**造型**和**聲音**標籤頁上，它搜尋該角色造型或聲音的名稱，並將列表跳到您的選擇。

## 導航結果

- **上 / 下箭頭**在下拉框中移動；**回車**轉到下一個匹配。
- **F3** 和 **Shift+F3** 在匹配中前進和後退。
- **Escape** 清除搜尋，然後關閉欄。
- 選擇結果會**將工作區滾動到該積木**，使其進入檢視。

當一個匹配出現在多個地方（一個變數被多次使用，或一個有多個呼叫者的自制積木）時，一個小**輪播**顯示 `當前 / 總數` 並帶箭頭；用左右箭頭迴圈每個出現，工作區依次滾動到每個。

您可以切換**區分大小寫**匹配（`Aa` 按鈕）和**正規表示式**匹配（`.*` 按鈕）。在按住 Shift 或中鍵點選工作區中的積木時，會開啟聚焦於該積木變數、自制積木或廣播的查詢欄，作為反向查詢。
