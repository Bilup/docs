**打包器**將專案變成獨立應用：一個 HTML 檔案、一個 zip，或 Windows、macOS、Linux 的原生應用，無需編輯器即可執行。它是一個獨立的工具，編輯器可以直接將當前專案交給它。

## 開啟打包器

**檔案，打包專案**（`Ctrl+P`）開啟[Bilup 打包器](/packager/overview)，並載入好您開啟的專案。您也可以單獨造訪 [packager.bilup.org](https://packager.bilup.org/) 並在那裡載入 `.sb3`。

## 打包是做什麼的

打包是您在 Bilup 站點之外分發完成專案的方式：

- 一個可以在任何地方託管或離線開啟的單個 **HTML 檔案**。
- 一個包含 HTML 及其資源的 **zip**。
- 用於桌面平臺的原生**執行檔**。

打包輸出嵌入 Bilup 的執行時和編譯器，因此打包專案以您選擇的[設定](/editor/settings)以全速執行。您可以在打包器本身中自訂載入螢幕、控制元件、雲端變數行為等。

## 分享與打包的區別

這些是不同的事情：

- **分享**專案（從其[專案頁面](/editor/project-management)）將其發佈在社群站點上，人們可以在瀏覽器播放器中玩它。
- **打包**產生一個您自己擁有和分發的檔案，不依賴 Bilup 站點。
