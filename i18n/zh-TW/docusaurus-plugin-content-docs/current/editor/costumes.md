title: 造型和畫板編輯器

每個角色都有一個或多個**造型**：它在[舞臺](/editor/stage)上顯示的影像。舞臺本身有**背景**，只是換了個名字的同一事物。**造型**標籤頁（選中舞臺時叫**背景**）列出它們並開啟內建畫板編輯器進行繪製和編輯。

## 造型列表

造型列表位於造型標籤頁的左側。每個條目顯示縮圖、造型名稱和以舞臺單位計的大小。點選造型選擇它並在舞臺上顯示；角色的當前造型是高亮的那一個。

右鍵單擊造型可以獲得**複製**、**匯出**（將影像以 `.svg` 或 `.png` 儲存到電腦）和**刪除**。您不能刪除角色最後一個剩餘的造型。拖動造型重新排序；順序就是 `下一個造型` 積木遍歷的順序。

## 新增造型

列表底部的圓形新增按鈕提供：

- **選擇一個造型** / **選擇一個背景**：從內建素材庫中選擇。
- **上傳造型** / **上傳背景**：從電腦載入影像。接受的型別是 `.svg`、`.png`、`.bmp`、`.jpg`、`.jpeg`、`.jfif`、`.webp` 和 `.gif`。您可以一次選擇多個檔案，每個都會成為一個造型。
- **隨機**：從素材庫中新增隨機造型。
- **繪製**：建立空白造型並開始繪製。
- **搜尋**：按名稱瀏覽素材庫。

您也可以從[背包](/editor/backpack)拖入造型。

## 點陣圖和向量

畫板編輯器以兩種模式工作，每個造型是其中一種：

- **向量**造型由形狀（路徑、橢圓、矩形、文本）組成。它們在任何尺寸下都保持清晰，並且是新造型的預設模式。Scratch 自己的美術是向量。
- **點陣圖**造型是畫素網格，像照片或 `.png`。它們適合畫素藝術和匯入的照片，但放大時會模糊。

畫布底部的一個按鈕在它們之間切換：**轉換為點陣圖**或**轉換為向量**。轉換會柵格化或描摹美術作品，因此往返並不總是無損的。

## 向量工具

開啟向量造型時，畫布左側的工具是：

- **選擇**：移動、調整大小、旋轉和群組形狀。
- **變形**：拖動路徑的各個點和曲線手柄。
- **畫筆**和**線條**：繪製徒手筆畫和直線。
- **橡皮擦**：擦除形狀的部分。
- **填充**：用顏色或漸變填充區域。
- **文本**：新增可編輯文本。
- **圓形**和**矩形**（包括圓角矩形）：繪製填充或輪廓形狀。

頂部是填充和輪廓顏色選擇器（每個都支援純色或漸變）、筆劃寬度，以及群組/解散群組、將形狀前移或後移、水平或垂直翻轉以及複製/貼上的操作。

## 點陣圖工具

開啟點陣圖造型時，工具集變為畫素對應物：**畫筆**、**線條**、**圓形**、**矩形**、**文本**、**填充**（油漆桶）、**橡皮擦**和**選擇**。這裡填充也支援純色和漸變。

## 造型畫布

- 畫布中心的十字準線標記角色的**旋轉中心**，即它圍繞旋轉的點，也是放置在其 `x`/`y` 位置的點。拖動它，或使用居中控制元件，來更改造型的樞軸。
- **縮放**控制元件位於畫布的右下角。
- **撤銷**和**重做**在編輯器頂部，畫布聚焦時常用的 `Ctrl+Z` / `Ctrl+Shift+Z` 快速鍵也有效。
