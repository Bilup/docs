title: 變數管理器

變數管理器是一個視窗，一次顯示每個[變數和列表](/editor/variables)，讓您在專案執行時即時讀取和更改它們的值。當您想監視或調整大量資料時，它比在舞臺上散佈監視器快得多。

## 開啟它

開啟**工具**選單並選擇**變數管理器**，點選舞臺控制元件中的按鈕，或按 `Ctrl+Shift+V`（macOS 上是 `Cmd+Shift+V`）。它開啟時，`Ctrl+F` 聚焦它的搜尋框，`Escape` 清除搜尋或關閉視窗。

## 它顯示什麼

變數和列表分為兩個部分：

- **此角色的變數**：您正在編輯的角色的區域性變數。
- **所有角色的變數**：全域變數（舞臺上的那些）。

每行顯示變數的名稱、當前值，以及**列表**或**雲**變數的徽章。列表顯示為多行框，每行一項。非常大的值隱藏在按鈕後面，以免拖慢編輯器。

## 您可以做什麼

- 按名稱或值**搜尋**，並按**全部 / 變數 / 列表 / 雲** **篩選**，每個都有即時計數。
- **編輯值**：輸入新值並提交。對於列表，每行成為一個專案。
- 透過編輯名稱**重新命名**變數（拒絕空白或重複名稱）。重新命名雲端變數會保留其雲字首。
- **重新整理**重新載入列表，專案執行時值會**即時**更新，因此您可以觀察它們變化。

變數管理器讀取和編輯現有變數；建立和刪除變數仍然透過[積木區](/editor/blocks-palette)中的**建立一個變數**和**建立一個列表**按鈕完成。

## 設定

它的選項位於[設定視窗](/editor/settings)的**變數管理器**頁面上：預設檢視、是否開啟即時更新、更新間隔，以及隱藏非常大值的大小限制。
