本頁涵蓋專案的生命週期：開始新專案、儲存它（到電腦或您的 Bilup 帳戶）、重新載入它、分享它和改編它。這些操作中的大多數位於[檔案選單](/editor/menu-bar)中。

## 新專案

**檔案，新建**清空工作區並開始一個的全新專案。如果當前專案有未儲存的更改，會先警告您，因為新專案會替換開啟的內容。

## 儲存

專案可以儲存到兩個獨立的地方：作為檔案儲存到電腦，或線上儲存到您的 Bilup 帳戶。它們不衝突；一個專案可以同時儲存到兩者。

### 儲存到電腦

- **檔案，儲存到（檔名）**或**另存為**將 `.sb3` 檔案寫入磁碟。在支援檔案系統存取 API 的瀏覽器上，儲存可以寫回您開啟的檔案；否則會正常下載。
- **檔案，從電腦載入**（`Ctrl+O`）從磁碟開啟 `.sb3`。

`.sb3` 是一個單一的自包含檔案：一個 ZIP 歸檔，包含 `project.json`（所有角色、指令碼、變數和設定）以及每個造型和聲音。它是專案的可移植、離線副本，可在 Scratch、TurboWarp 和 Bilup 中工作。

### 儲存到 Bilup

當您用[Bilup Accounts 帳戶](/getting-started/introduction)登入時，檔案選單顯示**儲存到 Bilup**（專案存在於那裡後，**立即儲存** / `Ctrl+S` 會儲存到您的帳戶）。這會將專案上傳到您的帳戶，讓您可以透過社群站點從任何裝置存取它。

- 上傳**不是**發佈。已儲存的專案在您分享之前對您保持私有。
- Bilup 高效上傳資源，只發送它尚未擁有的造型和聲音，因此重新儲存專案很快。

要製作獨立儲存的副本，請使用**檔案，另存為副本**（`Ctrl+Shift+S`）。

## 分享

分享是在社群站點上進行的，而不是透過編輯器的儲存操作。專案儲存到您的 Bilup 帳戶後，開啟它的專案頁面（**檔案，檢視專案頁面**，或[選單欄](/editor/menu-bar)中的帳戶區域）並使用那裡的**分享**按鈕。分享使專案對他人可見，並給它一個公開頁面和播放器。您從站點控制可見性。

## 改編

**改編**基於現有專案開始一個新專案，並註明原作者。**檔案，改編**（登入時是**改編到 Bilup**）建立您自己的副本，您可以更改並單獨儲存，不會觸及原件。改編是您基於別人的共享專案建置的方式。

## 自動儲存與還原點

您工作時有兩個安全網在執行：

- [還原點](/editor/restore-points)定期將整個專案快照到您的瀏覽器中，這樣您可以在出錯或崩潰後回滾。
- 可選的[自動儲存](/editor/restore-points)按計時器將專案重新儲存到當前位置。

兩者都不能取代刻意儲存，但都能降低忘記儲存的代價。
