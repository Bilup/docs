title: 積木區

積木區是**程式碼**標籤頁左側的列。它包含您可以使用的每個積木，按分類分組。將積木從積木區拖入[工作區](/editor/workspace)來將它新增到指令碼。

## 分類

積木區分為多個分類，每個分類有自己的顏色。標準分類是：

- [運動](/blocks/motion)、[外觀](/blocks/looks)、[聲音](/blocks/sound)
- [事件](/blocks/events)、[控制](/blocks/control)、[偵測](/blocks/sensing)
- [運算](/blocks/operators)、[變數](/blocks/variables)和[自制積木](/blocks/my-blocks)

最左側一條彩色圓點是目錄：點選一個圓點會將積木區直接滾動到該分類。每個分類的作用請參閱[積木概覽](/blocks/overview)。

**變數**分類還包含**建立一個變數**和**建立一個列表**按鈕（請參閱[變數和列表](/editor/variables)），**自制積木**包含用於[自制積木](/editor/custom-blocks)的**建立一個積木**。

## 搜尋

在積木區頂部的搜尋框中輸入，可以按名稱跨所有分類過濾積木。當您大致知道積木叫什麼時，這是找到它的最快方式。要跳轉到專案中已有的特定積木、變數或自制積木，請改用[查詢欄](/editor/find-bar)。

## 擴充功能新增分類

左下角的**新增擴充功能**按鈕開啟[擴充功能庫](/extensions/overview)。新增擴充功能（例如[畫筆](/extensions/pen)、[音樂](/extensions/music)或[文字朗讀](/extensions/text-to-speech)）會在積木區底部附加一個新分類，包含該擴充功能的積木。某些擴充功能還會新增用於連線硬體的狀態按鈕。

Bilup 還提供標準 Scratch 之外的額外內建積木；請參閱[Bilup 額外積木](/blocks/bilup-extras)。

## 調整大小與佈局

您可以拖動積木區和工作區之間的邊界來加寬或收窄積木區。幾個[設定](/editor/settings)會更改積木區：

- **隱藏擴充功能按鈕** 移除新增擴充功能的按鈕。
- **僅標準相容積木** 隱藏標準 Scratch 無法執行的積木（如返回積木、switch/case 積木和資源分類），當您希望專案保持與 scratch.mit.edu 相容時很有用。
- **隱藏可擴充功能運算積木的箭頭** 隱藏 `+` 和 `連線` 等積木上的加號/減號箭頭。
