Bilup 編輯器是您建置專案的地方。它完全在瀏覽器中執行（也可以在桌面應用中），並與社群站點來自同一建置。本頁是編輯器視窗的地圖：每個區域是什麼以及在哪裡閱讀更多內容。

## 佈局一覽

編輯器分為幾個固定區域：

- **選單欄**橫跨頂部：Bilup 徽標（返回主頁的連結）、檔案 / 編輯 / 工具 / 書籤選單、設定、專案標題，右側是儲存狀態和帳戶。請參閱[選單欄](/editor/menu-bar)。
- **舞臺**在一邊：執行中的專案、綠旗和停止按鈕、舞臺大小控制元件和全屏按鈕。請參閱[舞臺](/editor/stage)。
- **角色面板**在舞臺下方：角色列表、所選角色的屬性（位置、大小、方向、可見性）以及舞臺/背景選擇器。請參閱[角色](/editor/sprites)。
- **編輯區域**佔據視窗的其餘部分，由左上角的三個標籤頁控制：
  - **程式碼**：[積木區](/editor/blocks-palette)和[積木工作區](/editor/workspace)。
  - **造型**（選中舞臺時是**背景**）：[畫板編輯器](/editor/costumes)。
  - **聲音**：[聲音編輯器](/editor/sounds)。

三個標籤頁切換編輯區域為當前選中的角色或舞臺顯示的內容。舞臺、角色面板和選單欄在切換標籤頁時保持不變。

## 編輯器模式與播放器模式

同一個頁面可以兩種方式渲染。在**編輯器模式**下您會看到上面所有內容。在**播放器模式**下只顯示舞臺及其控制元件，這是訪客在共享專案頁面或嵌入中看到的。社群專案頁面將專案載入到嵌入的播放器中，而不是完整的編輯器。

## Bilup 編輯器有何不同

除了標準的 Scratch 佈局，Bilup 編輯器還增加了：

- 一個將您的積木轉換為 JavaScript 以提高速度的[編譯器](/blocks/overview)，以及[自訂 FPS](/advanced/custom-fps)、[自訂舞臺大小](/advanced/custom-stage-size)和其他[進階設定](/editor/settings)。
- 重塑和重設編輯器樣式的[外掛](/editor/addons)和[自訂主題](/editor/themes)。
- 開發者工具：[偵錯器](/editor/debugger)、[變數管理器](/editor/variable-manager)、[還原點](/editor/restore-points)和自動儲存、內建的[Git 版本控制](/editor/git)以及[即時協作](/editor/collaboration)。
- 用於在大型專案中導航的[查詢欄](/editor/find-bar)和[工作區書籤](/editor/bookmarks)。
