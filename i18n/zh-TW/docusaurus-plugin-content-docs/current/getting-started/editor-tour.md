# 編輯器導覽

這是 Bilup 編輯器的導覽。每個區域都連結到其完整的參考頁面。關於各區域如何組合的概述，請參閱[編輯器介面](/editor/interface)。

編輯器在頂欄下方分為三列：

- 頂部是**選單欄**，
- 左側和中間是**積木區**和**工作區**（位於程式碼標籤頁），
- 右側是**舞臺**和**角色區**。

## 選單欄

頂部的橫條包含**檔案**和**編輯**選單、專案標題、**設定**選單，以及（登入後）您的帳戶和通知。從這裡您可以建立、儲存、載入、打包和發佈專案，也可以存取外掛、還原點、git 和教程。

- 檔案與編輯選單、儲存、發佈和打包：[選單欄](/editor/menu-bar)
- 編輯器自身的偏好設定：[設定](/editor/settings)

## 三個編輯器標籤頁

積木區上方有三個標籤頁，用於切換左側和中間列顯示的內容：

- **程式碼**顯示積木區和工作區（見下文）。
- **造型**顯示所選角色造型的畫板編輯器（選中舞臺時顯示**背景**）。請參閱[造型](/editor/costumes)。
- **聲音**顯示聲音編輯器。請參閱[聲音](/editor/sounds)。

## 積木區

在程式碼標籤頁中，左側列出所有積木，按類別分組（運動、外觀、聲音、事件、控制、偵測、運算、變數、自制積木），擴充功能位於下方。將積木從拖到這裡到工作區。

- 積木區本身：[積木區](/editor/blocks-palette)
- 每個分類的用途：[積木概覽](/blocks/overview)
- 新增擴充功能積木：[擴充功能概覽](/extensions/overview)

## 工作區

中間區域用於透過吸附積木來組裝指令碼。它支援右鍵選單、註解和清理，以及 Bilup 自己用於查詢和組織程式碼的工具。

- 工作區本身：[工作區](/editor/workspace)
- 跳轉到任意積木或變數：[查詢欄](/editor/find-bar)
- 在大型專案中儲存並跳轉到指定位置：[書籤](/editor/bookmarks)
- 定義自己的積木：[自制積木](/editor/custom-blocks)

## 舞臺

右上方是舞臺，專案在其中執行，其上方有綠旗和停止按鈕。舞臺下方是用於選擇和編輯背景的**舞臺選擇器**。

- 舞臺及其控制：[舞臺](/editor/stage)
- 執行限制和渲染選項：[自訂舞臺大小](/advanced/custom-stage-size)和[自訂 FPS](/advanced/custom-fps)

## 角色區

右側舞臺下方是角色列表，上方是角色資訊控制（名稱、位置、大小、可見性），角落有新增角色按鈕。

- 管理角色：[角色](/editor/sprites)
- 跨專案複用角色、造型、聲音和指令碼：[背包](/editor/backpack)

## 變數與資料

變數和列表在積木區的**變數**類別中建立，並作為監視器顯示在舞臺上。Bilup 增加了一個管理器，可同時處理大量變數。

- 使用變數和列表：[變數](/editor/variables)
- 批次編輯和檢查：[變數管理器](/editor/variable-manager)

## Bilup 工具

以下是從選單和設定中存取的、Bilup 在標準編輯器之外新增的功能：

- 可選的編輯器和播放器功能：[外掛](/editor/addons)
- 配色方案和深色模式：[主題](/editor/themes)
- 單步執行執行中的專案：[偵錯器](/editor/debugger)
- 自動儲存和手動快照：[還原點](/editor/restore-points)
- 版本控制：[Git](/editor/git)
- 即時協作編輯專案：[協作](/editor/collaboration)
- 建置獨立版本：[打包](/editor/packaging)
- 重新繫結編輯器快速鍵：[快速鍵](/editor/shortcuts)
