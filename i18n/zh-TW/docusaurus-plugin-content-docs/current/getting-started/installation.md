# 安裝

Bilup 是免費開源的。沒有任何需要購買的東西，網頁版也無需安裝。您可以透過三種方式使用它：在瀏覽器中、作為桌面應用，或者作為單個專案的打包獨立建置。

## 在網頁上使用

在任何現代瀏覽器中開啟 [com.bilup.org](https://com.bilup.org/)。編輯器載入完成後即可立即開始創作。建立、編輯、儲存到電腦或開啟 `.sb3` 檔案都不需要帳戶。

當您想要以下功能時，可以使用 **Bilup Accounts 帳戶**登入：

- 將專案發佈到 Bilup 社群，
- 關注他人、評論並顯示在您的個人資料中，
- 在裝置之間同步設定和主題。

這些功能以後再做也可以；開始創作並不需要帳戶。

### 儲存工作成果

沒有帳戶時，使用 **檔案然後儲存到電腦** 下載 `.sb3` 檔案，使用 **檔案然後從電腦載入** 重新開啟。有帳戶時，**檔案然後儲存到 Bilup** 會將專案發佈到社群平臺並儲存在您的帳戶中。完整的儲存與分享流程請參閱[專案管理](/editor/project-management)。

## 桌面應用

Bilup 有一個桌面應用，可以在自己的視窗中執行相同的編輯器，而不是瀏覽器標籤頁。桌面版增加了網頁無法提供的便利功能，例如多編輯器視窗和原生檔案處理。請從 [github.com/Bilup/desktop/releases](https://github.com/Bilup/desktop/releases) 下載當前版本。

桌面應用是可選的。所有核心功能在網頁版中都可用。

## 打包專案

[Bilup 打包器](https://packager.bilup.org/) 可以將單個專案轉換為可分發獨立程式：HTML 檔案、zip 壓縮包或原生執行檔，所有這些都不需要編輯器即可執行。這不是 Bilup 本身的安裝程式；而是用於製作專案的建置工具。

您可以透過 **檔案然後打包專案**（Ctrl+P）將當前專案直接傳送到打包器。更多選項（如離線建置、自訂舞臺縮放和商業用途）請參閱[打包器概覽](/packager/overview)。

## 瀏覽器支援

Bilup 支援當前版本的 Chrome、Edge、Firefox 和 Safari。它需要 JavaScript、WebGL 和 Web Audio API，這些瀏覽器預設都提供。如果舞臺無法渲染，請檢查瀏覽器設定中是否啟用了硬體加速和 WebGL。
