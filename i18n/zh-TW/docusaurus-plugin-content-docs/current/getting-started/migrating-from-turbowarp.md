# 從 TurboWarp 遷移

Bilup 建構在 TurboWarp 之上，因此如果您已經在使用 TurboWarp，編輯器看起來和使用起來幾乎完全相同。編譯器、任意幀率、自訂舞臺大小、外掛、主題、還原點、打包器和進階設定都會保留，並按您的預期工作。專案使用相同的 `.sb3` 格式，TurboWarp 專案可以透過 **檔案然後從電腦載入** 直接在 Bilup 中開啟。

本頁重點介紹 Bilup 在 TurboWarp 基礎上新增的功能。

## 社群平臺與 Bilup Accounts

最大的新增功能是完整的社群平臺。Bilup 編輯器和社群站點由同一個建置提供，因此發佈、個人資料和瀏覽專案都整合在同一個應用中。

- 使用 **Bilup Accounts 帳戶**登入。在選單欄中，您可以透過 **檔案然後儲存到 Bilup** 將專案直接儲存到帳戶，然後開啟其專案頁面。
- 登入後，您會獲得個人資料、通知和社交功能（關注、評論和發帖）。
- 登入狀態下，您的設定和主題會在裝置間同步。

建置、執行、打包或本地儲存專案不需要帳戶，這與 TurboWarp 完全一致。帳戶只增加社群功能。請參閱[專案管理](/editor/project-management)。

## 額外積木與擴充功能

Bilup 包含超出 TurboWarp 的額外積木和擴充功能。請在[擴充功能概覽](/extensions/overview)和[Bilup 額外積木](/blocks/bilup-extras)中瀏覽。

## Git 版本控制

Bilup 可以用 **git** 跟蹤專案。專案一旦存在倉庫，檔案選單就會為遠端倉庫提供提交、推送和拉取操作，因此您可以透過 git 託管來管理版本並與他人協作。請參閱[Git](/editor/git)。

## 即時協作

Bilup 增加了即時協作：多人可以同時編輯同一個專案，並看到彼此在編輯器中的存在。請參閱[協作](/editor/collaboration)。

## 偵錯器

Bilup 包含一個偵錯器，用於檢查執行中的專案、單步執行並觀察狀態，這超出了 TurboWarp 的標準工具。請參閱[偵錯器](/editor/debugger)。

## 主題與外掛

TurboWarp 的外掛和主題系統都存在並得到擴充功能。Bilup 提供自己的主題（包括自訂配色方案）和自己精選的外掛。請參閱[主題](/editor/themes)和[外掛](/editor/addons)。

## 相同之處

- 積木、編譯器和執行時行為。請參閱[積木概覽](/blocks/overview)。
- 進階設定，如[自訂 FPS](/advanced/custom-fps)、[自訂舞臺大小](/advanced/custom-stage-size)、[高質量畫筆](/advanced/high-quality-pen)、[插值](/advanced/interpolation)和[移除限制](/advanced/remove-limits)。
- 用於建置專案獨立版本的[打包器](/packager/overview)。
- URL 引數、嵌入和雲端變數。請參閱[URL 引數](/advanced/url-parameters)、[嵌入](/advanced/embedding)和[雲端變數](/advanced/cloud-variables)。
