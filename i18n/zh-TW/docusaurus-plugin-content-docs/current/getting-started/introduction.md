# 簡介

Bilup 是一個基於 TurboWarp 的 Scratch 修改版。如果您用過 Scratch，Bilup 會讓您感到熟悉：相同的積木、角色、造型和舞臺。在此基礎之上，它還增加了效能最佳化、自訂能力、開發者工具和社群平臺。

編輯器和社群站點是同一個應用。您可以開啟 [com.bilup.org](https://com.bilup.org/) 立即開始創作，無需帳戶，也無需安裝任何東西。

## Bilup 新增了什麼

- **編譯器**：將您的積木編譯為 JavaScript，使專案比標準 Scratch 直譯器執行得更快。如需關閉它做對比，請參閱[停用編譯器](/advanced/disable-compiler)。
- **任意幀率**和**自訂舞臺大小**，取代固定的 30 FPS 和 480x360。請參閱[自訂 FPS](/advanced/custom-fps)和[自訂舞臺大小](/advanced/custom-stage-size)。
- **外掛**：可改變編輯器和播放器行為的小型可選功能。請參閱[外掛](/editor/addons)。
- **主題**，包括深色模式和完全自訂的配色方案。請參閱[主題](/editor/themes)。
- **偵錯器**，用於單步執行和檢查執行中的專案。請參閱[偵錯器](/editor/debugger)。
- **還原點**和自動儲存，避免丟失工作成果。請參閱[還原點](/editor/restore-points)。
- **Git 版本控制**和**即時協作**，便於長期管理和多人共同開發專案。請參閱[Git](/editor/git)和[協作](/editor/collaboration)。
- **打包器**，可將專案轉換為獨立應用或網頁。請參閱[打包器](/packager/overview)。
- **社群平臺**，支援帳戶、發佈專案、關注他人和評論。帳戶透過 Bilup Accounts 處理；關於社群功能如何運作，請參閱[從 TurboWarp 遷移](/getting-started/migrating-from-turbowarp)。

## 面向的讀者

Bilup 同時面向兩類讀者，本文件也為他們而寫：

- 如果您**來自 Scratch**，您已經掌握的所有知識仍然適用。請從[從 Scratch 遷移](/getting-started/migrating-from-scratch)和[快速入門](/getting-started/quick-start)開始。
- 如果您是**進階使用者或開發者**，Bilup 透過 JavaScript、自訂擴充功能和文件化的 API 開放了執行時。請參閱[JavaScript](/advanced/javascript)、[建置擴充功能](/building-extensions/introduction)和[API 參考](/api-reference/overview)。
