# 快速入門

本頁將從空白編輯器開始建置一個可執行的小專案。整個過程只需幾分鐘，並且假設您沒有 Bilup 使用經驗。如果您也沒用過 Scratch，積木系統與 Scratch 相同；相關概念請參閱[從 Scratch 遷移](/getting-started/migrating-from-scratch)。

## 開啟編輯器

前往 [com.bilup.org](https://com.bilup.org/)。會開啟一個新專案，本頁上的所有操作都不需要帳戶。

## 新增程式碼

編輯器預設開啟在**程式碼**標籤頁。[積木區](/editor/blocks-palette)在左側，按類別分組；[工作區](/editor/workspace)在中間，用於擺放指令碼。

1. 從**事件**類別中，將 `當綠旗被點選` 積木拖入工作區。這是一個帽子積木：專案執行時它會啟動一個指令碼。
2. 從**外觀**中，將 `說 [你好！] (2) 秒` 積木拖出並吸附在帽子積木下方。
3. 從**運動**中，在下面拖入一個 `移動 (10) 步` 積木。
4. 從**控制**中，拖入一個 `重複執行` 積木，用它包裹住 `移動` 積木，讓角色持續移動。

當積木的凹槽對齊時，它們就會吸附在一起。要拔出積木，請將其拖走；要刪除積木，請將其拖回積木區。

## 執行它

右側[舞臺](/editor/stage)上方是綠旗和停止按鈕。點選**綠旗**執行您的指令碼；角色會問好並開始移動。點選**停止按鈕**停止。按空格鍵也可以切換執行狀態。

如果角色走出邊緣，請從**運動**中新增一個 `碰到邊緣就反彈` 積木，放在 `重複執行` 迴圈內。

## 改變外觀

- **造型**標籤頁可以讓您繪製或編輯角色的外觀。請參閱[造型](/editor/costumes)。
- **聲音**標籤頁用於管理音訊。請參閱[聲音](/editor/sounds)。
- 使用[角色區](/editor/sprites)右下角的角色按鈕新增更多角色，並透過旁邊的[舞臺選擇器](/editor/stage)更換背景。

## 儲存

- **檔案然後儲存到電腦** 會下載一個 `.sb3` 檔案。此操作無需帳戶，該檔案也可以在 Scratch 和 TurboWarp 中開啟。
- **檔案然後從電腦載入** 稍後重新開啟 `.sb3` 檔案。
- 使用 Bilup Accounts 帳戶時，**檔案然後儲存到 Bilup** 會將專案發佈到您的帳戶和社群。請參閱[專案管理](/editor/project-management)。

Bilup 還會在後臺儲存[還原點](/editor/restore-points)並自動儲存，因此崩潰或誤重新整理不會丟失您的工作成果。
