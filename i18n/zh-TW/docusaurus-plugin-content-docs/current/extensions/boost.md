# LEGO BOOST

**LEGO BOOST**擴充功能控制 LEGO BOOST 移動集線器，包括它的馬達、顏色感測器和傾斜偵測。它是內建的，並且與 Scratch 相容。

從**新增擴充功能**載入它並選擇 **LEGO BOOST**。

## 要求

BOOST 透過藍牙連線，因此您需要：

- 一臺帶藍牙和支援的瀏覽器的電腦。
- **Scratch Link** 執行以將藍牙橋接到瀏覽器。
- BOOST 移動集線器與您的電腦配對。

新增擴充功能會開啟連線視窗以配對集線器。

## 積木

### 將馬達 `[馬達]` 開啟 `[時長]` 秒

執行馬達一段設定時間。

### 將馬達 `[馬達]` 開啟 `[轉數]` 轉

執行馬達一定轉數。

### 將馬達 `[馬達]` 開啟 / 關閉

啟動或停止馬達。

### 將馬達 `[馬達]` 速度設為 `[功率]` %

將馬達速度從 0 設定為 100 百分比。

### 將馬達 `[馬達]` 方向設為 `[方向]`

將馬達設定為**朝這個方向**、**朝那個方向**或**反轉**執行。

### 馬達 `[馬達]` 位置

馬達旋轉位置的報告積木。

### 當看到 `[顏色]` 積木 / 看到 `[顏色]` 積木?

響應顏色感測器檢測到彩色積木，作為帽子積木或布林積木。

### 當傾斜 `[方向]` / 傾斜角度 `[方向]`

響應傾斜集線器，或讀取它的傾斜角度。

### 將燈光顏色設為 `[色相]`

設定集線器內建燈光的顏色。
