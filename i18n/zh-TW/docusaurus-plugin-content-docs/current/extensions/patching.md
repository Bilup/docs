# 補丁

**補丁**擴充功能讓您在積木中編寫原始 JavaScript。專案編譯時，該 JavaScript 被直接注入生成的程式碼中，並作為編譯執行緒的一部分執行。它是內建的，並被標記為與 Scratch 不相容。

從**新增擴充功能**載入它並選擇**補丁**。

## 積木

### js `[程式碼]`（報告）

```scratch
(js [1 * 3])
```

計算 JavaScript 表示式並返回其值。預設文本是 `1 * 3`，報告 `3`。

### js `[程式碼]`（布林）

```scratch
<js [1 === 1]>
```

計算 JavaScript 表示式並將其作為布林值報告。

### js `[程式碼]`（命令）

```scratch
js [console.log("hello")]
```

將 JavaScript 作為語句執行，用於產生副作用。預設文本將 `hello` 記錄到控制台。

## 需要編譯器

補丁積木只在編譯器開啟時工作。積木體被拼接到編譯輸出中；沒有直譯器回退，因此如果編譯器被停用，積木會丟擲 `補丁積木需要編譯器`。確保編譯器已啟用（預設啟用）。編譯如何控制請參閱[停用編譯器](/advanced/disable-compiler)。

## 安全與穩定性風險

::::warning
補丁以與頁面其餘部分相同的存取許可權執行您放入積木中的任何 JavaScript。請像對待您從網際網路貼上的任何程式碼一樣對待它。
::::

- 只使用您理解的程式碼。補丁積木可以讀取和更改專案能做的任何事情，包括髮出網路請求。
- 除非您信任作者，否則永遠不要載入使用補丁積木的共享專案，原因相同。
- 因為程式碼被注入編譯輸出中，語法錯誤或執行時異常可能破壞整個編譯執行緒，而不只是那一個積木。
- 表示式形式（`js` 報告和布林）應該是一個單個表示式。命令形式接受語句。

要以結構化的方式編寫參與編譯專案的 JavaScript，請參閱[編譯擴充功能](/building-extensions/compiled/overview)，這是超出快速一行之外任何內容的受支援路徑。
