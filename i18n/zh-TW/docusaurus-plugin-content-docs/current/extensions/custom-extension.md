# 自訂擴充功能

**自訂擴充功能**庫專案載入不在內建列表中的擴充功能。您可以將其指向 URL、上傳本地檔案，或直接貼上 JavaScript 原始碼。

開啟**新增擴充功能**並選擇**自訂擴充功能**。

## 載入方式

- **從 URL** - 貼上以 `.js` 結尾的連結。這是從 [extensions.bilup.org](https://extensions.bilup.org/) 等畫廊載入社群擴充功能的方式。URL 會與專案一起儲存，因此專案開啟時會從同一 URL 重新載入擴充功能。
- **從檔案** - 從電腦上傳 `.js` 檔案。擴充功能的程式碼嵌入在專案中。
- **從文本** - 直接貼上 JavaScript 原始碼。

## 沙箱與非沙箱

載入自訂擴充功能時，您選擇以沙箱還是非沙箱方式執行它。

- **沙箱**擴充功能在隔離的 worker 中執行。它們可以新增積木並進行計算，但不能直接接觸頁面、VM 內部或渲染器。這是更安全的預設選項，對大多數擴充功能來說足夠了。
- **非沙箱**擴充功能以對執行時、渲染器和頁面的完全存取許可權執行。它們可以做沙箱擴充功能做不到的事情（讀取角色狀態的自訂報告積木、直接渲染等），但它們也可以做頁面能做的任何事情。

作為使用者，除非擴充功能特別需要非沙箱存取，否則優先使用沙箱。如果您在編寫擴充功能，[沙箱](/building-extensions/sandbox)和[非沙箱](/building-extensions/unsandboxed)詳細說明了權衡。

## 安全提示

::::warning
載入自訂擴充功能會執行別人的程式碼。只從您信任的來源載入擴充功能。
::::

在來自 URL 或檔案的擴充功能執行之前，Bilup 會顯示提示，告訴您它來自哪裡，並讓您取消。非沙箱擴充功能承擔更多風險，因為它們不被隔離。如果您不是有意載入擴充功能，或者您不識別來源，請取消。惡意擴充功能可以讀取您的專案、發出網路請求並干擾頁面。

## 載入後

自訂擴充功能積木像內建擴充功能一樣作為自己的分類出現。擴充功能與專案一起儲存，因此您不必每次會話都重新載入它，其他開啟專案的人會得到相同的積木（從同一 URL 載入，或者如果您從檔案或文本載入則嵌入）。
