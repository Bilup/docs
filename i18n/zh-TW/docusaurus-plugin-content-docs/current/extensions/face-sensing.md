# 人臉感知

**人臉感知**擴充功能檢測網路攝影機中的面部，並報告其特徵的位置，因此角色可以跟隨您的鼻子、坐在您的頭上，或在您傾斜時做出反應。它是一個遠端擴充功能，不與編輯器捆綁。

從**新增擴充功能**載入它並選擇**人臉感知**。

## 遠端載入，需要攝影機

人臉感知不與編輯器捆綁。您第一次載入它時，Bilup 會從遠端 URL 下載它，因此您需要網際網路連線來載入它（一旦載入並儲存，它會隨專案重新載入）。與影片偵測一樣，它需要網路攝影機許可權才能執行。

## 積木

該擴充功能提供幾組積木：

- **面部檢測**：一個在*檢測到面部時*執行的帽子積木，以及一個布林積木*檢測到面部?*，讓您可以在指令碼的任何地方檢查面部。
- **面部大小**：一個*面部大小*報告積木，報告檢測到面部的大小，以及一個將角色大小設定為與面部匹配的命令。
- **面部傾斜**：一個*面部傾斜*報告積木、一個在*面部向左或向右傾斜時*執行的帽子積木，以及一個讓角色朝向傾斜方向的命令。
- **特徵位置**：報告面部部位位置的報告積木，包括兩眼之間、每隻眼睛、鼻子、嘴、每隻耳朵和頭頂，以及一個將角色移動到這些部位中任何一個的*移到*命令。

確切的積木措辭來自擴充功能本身；在編輯器中開啟它檢視完整列表。

## 提示

- 一次只跟蹤一個面部，因此這最適合單個人在光線合理的情況下面對攝影機。
- 將*移到*面部部位與角色造型結合，製作跟隨您面部的帽子、眼鏡或面具。
- 如果檢測無法啟動，通常是攝影機許可權或光線問題，而不是專案 bug。
