# Bilup 積木

**Bilup 積木**擴充功能（內部 id `tw`）新增一組標準 Scratch 沒有的額外輸入積木。它是內建的，可即時載入，並被標記為與 Scratch 不相容，因此使用它的專案無法在 scratch.mit.edu 上執行。

從**新增擴充功能**載入它並選擇**Bilup 積木**。

## 積木

### 最後按下的鍵

```scratch
(最後按下的鍵)
```

一個報告積木，返回使用者最近按下的鍵的鍵名（例如 `空格`、`a`、`上箭頭`）。對選單、文本輸入或讓播放者重新繫結控制而不逐個檢查每個鍵很有用。

### `[按鈕]` 滑鼠按鈕按下?

```scratch
<(0) 滑鼠按鈕按下?>
```

一個布林積木，報告特定滑鼠按鈕當前是否被按住。下拉框提供：

- **(0) 主按鈕**（通常是左鍵）
- **(1) 中鍵**（滾輪按鈕）
- **(2) 次按鈕**（通常是右鍵）

下拉框接受報告積木，因此您可以在執行時計算按鈕編號。這讓您能檢測右鍵和中鍵點選，而標準的 `滑鼠按下?` 積木無法區分。

## 提示

- 這些積木讀取與標準偵測積木相同的鍵盤和滑鼠狀態，因此它們在編輯器中和打包器中都能工作。
- 因為該擴充功能與 Scratch 不相容，如果您計劃將專案發佈到 scratch.mit.edu，請避免使用。對於僅限 Bilup 的專案，可以放心依賴。
