# 擴充功能概覽

擴充功能向積木區新增核心積木分類之外的額外積木。一個擴充功能可以新增一整套新樂器、透過藍牙驅動實體機器人、讀取網路攝影機，或將原始 JavaScript 注入您編譯的專案。載入後，它的積木作為積木區底部的一個新分類出現。

## 新增擴充功能

點選編輯器左下角的**新增擴充功能**按鈕（積木區下方的圖示）。這會開啟擴充功能庫。點選任何擴充功能來載入它。它的積木會立即新增到您的專案中，並與專案一起儲存，因此任何後來開啟專案的人都會得到相同的積木。

一些擴充功能做的不僅是新增積木：

- **硬體擴充功能**（micro:bit、LEGO、Vernier 感測器）會開啟連線對話方塊，讓您在積木做任何事情之前透過藍牙配對裝置。
- **攝影機擴充功能**（影片偵測、人臉感知）第一次執行時向您的瀏覽器請求網路攝影機許可權。

## 內建與遠端擴充功能

Bilup 在庫中提供兩種擴充功能：

- **內建**擴充功能與編輯器捆綁，可離線即時載入。這些包括 Bilup 積木、補丁、音樂、畫筆、影片偵測、文字朗讀、翻譯、Makey Makey 和硬體擴充功能。
- **遠端**擴充功能在您第一次載入時從 URL 下載，因此它們需要網際網路連線才能載入。人臉感知就是其中之一。庫還連結到 [extensions.bilup.org](https://extensions.bilup.org/) 的完整 Bilup 擴充功能畫廊，那裡託管著數百個社群擴充功能。

一些內建擴充功能也需要網際網路才能真正工作（不只是載入）：文字朗讀和翻譯每次使用都會呼叫線上服務，硬體擴充功能可能獲取韌體或連線資源。

## 載入自訂擴充功能

如果擴充功能不在庫中，您可以自己從 URL、本地檔案或貼上的 JavaScript 原始碼載入。開啟擴充功能庫並選擇**自訂擴充功能**。詳情請參閱[自訂擴充功能](/extensions/custom-extension)，包括沙箱和非沙箱擴充功能之間的區別以及您會看到的安全提示。

## 與 Scratch 的相容性

一些擴充功能被標記為與 Scratch 不相容（Bilup 積木、補丁和大多數自訂擴充功能）。使用它們的專案無法在 scratch.mit.edu 上執行。庫在載入其中一個之前會警告您。來自 Scratch 本身的擴充功能（音樂、畫筆、影片偵測、文字朗讀、翻譯、Makey Makey 以及 LEGO / micro:bit / Vernier 硬體擴充功能）保持與 Scratch 相容。
