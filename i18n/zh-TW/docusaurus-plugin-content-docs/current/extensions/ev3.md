# LEGO MINDSTORMS EV3

**LEGO MINDSTORMS EV3**擴充功能驅動 LEGO MINDSTORMS EV3 主機上的馬達並讀取感測器。它是內建的，並且與 Scratch 相容。

從**新增擴充功能**載入它並選擇 **LEGO MINDSTORMS EV3**。

## 要求

EV3 透過藍牙連線，因此您需要：

- 一臺帶藍牙和支援的瀏覽器的電腦。
- **Scratch Link** 執行以將藍牙橋接到瀏覽器。
- EV3 主機與您的電腦配對。

新增擴充功能會開啟連線視窗以配對主機。馬達和感測器透過它們插入的埠定址。

## 積木

### 馬達 `[埠]` 朝這個方向轉 `[時間]` 秒

在給定埠上按一個方向執行馬達若干秒。

### 馬達 `[埠]` 朝那個方向轉 `[時間]` 秒

按相反方向執行馬達若干秒。

### 馬達 `[埠]` 功率設為 `[功率]` %

設定馬達驅動的力度，從 0 到 100 百分比。

### 馬達 `[埠]` 位置

馬達當前旋轉位置的報告積木。

### 當按鈕 `[埠]` 被按下

一個在給定埠上的觸控感測器被按下時執行的帽子積木。

### 當距離 < `[距離]` / 當亮度 < `[距離]`

在距離或光感測器讀數低於某個值時執行的帽子積木。

### 按鈕 `[埠]` 被按下?

一個觸控感測器當前是否被按下的布林積木。

### 距離 / 亮度

當前距離和光感測器讀數的報告積木。

### 蜂鳴音符 `[音符]` `[時間]` 秒

在主機揚聲器上播放音調。
