# 影片偵測

**影片偵測**擴充功能在舞臺上顯示您的網路攝影機並測量其中的運動，因此角色可以對您揮手或在攝影機前移動做出反應。它是內建的，並且與 Scratch 相容。

從**新增擴充功能**載入它並選擇**影片偵測**。

## 需要攝影機

影片第一次開啟時，您的瀏覽器會請求使用網路攝影機的許可權。影片偵測檢測攝影機影像中運動的大小和方向；它不識別面部或物體。面部檢測請參閱[人臉感知](/extensions/face-sensing)。

## 積木

### 當影片運動大於 `[閾值]`

```scratch
當影片運動大於 (10)
```

一個帽子積木，每當測量的運動超過給定閾值時執行其指令碼。

### 影片 `[屬性]` 在 `[物件]` 上

```scratch
(影片 (運動 v) 在 (角色 v) 上)
```

當前影片讀數的報告積木。**屬性**是**運動**（多少運動）或**方向**（朝哪個方向移動）。**物件**是**角色**（只在此角色上方的區域）或**舞臺**（整個舞臺）。

### 將影片 `[狀態]`

```scratch
將影片 (開啟 v)
```

將攝影機畫面**開啟**、**關閉**或**開啟翻轉**（左右映象，通常感覺更自然）。

### 將影片透明度設為 `[透明度]`

```scratch
將影片透明度設為 (50)
```

設定攝影機影像在舞臺上的透明程度，從 0（不透明）到 100（不可見）。即使影片完全透明，運動偵測仍然有效。

## 提示

- 運動是在影片幀之間測量的，因此靜態場景讀數接近零，快速運動讀數高。
- 使用*在角色上*讓每個角色只響應自己區域的運動，例如透過揮手"按"的按鈕。
