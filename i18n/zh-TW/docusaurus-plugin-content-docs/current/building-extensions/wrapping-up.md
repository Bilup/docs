# 結束

那是自訂擴充功能開發的核心。從這裡開始，參考頁面深入 API 表面的每個部分：

- [Scratch 物件 API](/building-extensions/apis/scratch-api)：完整的 `Scratch` 物件、積木工具和許可權 API。
- [VM API](/building-extensions/apis/vm-api)：執行時、目標、執行緒和事件。
- [渲染器 API](/building-extensions/apis/renderer-api)：直接繪製皮膚和可繪製物件。
- [音訊 API](/building-extensions/apis/audio-api)：音訊引擎、聲音播放器和效果。
- [實用 API](/building-extensions/apis/utility-apis)：`Scratch.Cast` 和相關輔助工具的詳細內容。

如果您需要原生速度的積木，[編譯擴充功能](/building-extensions/compiled/overview)部分展示瞭如何透過 Bilup 的編譯器直接生成 JavaScript。

## 獲取幫助和貢獻

您可以在 [extensions.bilup.org](https://extensions.bilup.org) 瀏覽 Bilup 擴充功能畫廊，並找到它的提交說明。

感謝您讀到這裡。
