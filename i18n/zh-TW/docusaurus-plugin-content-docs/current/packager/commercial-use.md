# 我可以出售用打包器製作的專案嗎?

::::note
我們不是律師，這不是法律建議。如果這對您很重要，請諮詢真正的律師。
::::

可以。如果您擁有專案內所有內容（其造型、聲音、指令碼和擴充功能）的權利，您可以出售用[Bilup 打包器](/packager/overview)打包的專案。

打包器捆綁的 Scratch 和 Bilup 開源元件在允許您免費（無費用或版稅）使用、修改、分發和出售打包專案的授權下發佈。這些授權也不附帶任何保證。某些部分使用"弱"copyleft 授權，如[Mozilla Public License 2.0](https://mozilla.org/MPL/2.0/)：粗略地說，如果您修改了那些特定檔案，您必須在同一授權下分享那部分特定程式碼。僅僅打包專案不會觸發這一點。

## 資源和他人的作品

如果您的專案使用他人制作的造型、聲音、指令碼或擴充功能，請確保您擁有出售它的許可。Scratch 網站上的大多數材料旨在 [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/) 下提供，它不禁止轉售，但確實要求署名並帶有可能產生實際影響的相同方式共享條款。創作者可以選擇在此基礎上授予您額外許可。

Scratch 商標（Scratch 徽標、Scratch 貓、Gobo、Pico 等）不在該授權範圍內，因此您可能沒有商業使用它們的許可。

有關 Scratch 自己的指南，請參閱[Scratch FAQ](https://scratch.mit.edu/faq) 中"我是否可以使用/改編 Scratch 支援材料..."和"我可以出售我的 Scratch 專案嗎?"的答案。
