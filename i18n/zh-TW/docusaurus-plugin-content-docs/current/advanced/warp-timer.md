# 防卡死計時器

防卡死計時器讓指令碼檢查是否卡在長迴圈或無限迴圈中，並降到低幀率，而不是讓整個專案凍結直到迴圈結束。這可以防止大多數"專案無響應"的崩潰，但它有真實的效能代價，因此預設只在編輯器中開啟，播放器中不開啟。可以在[編輯器設定](/editor/settings)或透過 [`stuck` URL 引數](/advanced/url-parameters)（也接受 `warp_timer`）切換。

作為演示，考慮一個在"不重新整理螢幕"積木內有無限迴圈的專案。開啟防卡死計時器後，專案會以低幀率（每秒幾幀）繼續渲染。關閉時，指令碼永遠不會讓出，專案看起來像凍結了。

防卡死計時器以前被稱為"卡死檢查"。
