# 無限克隆

Scratch 將專案同時存在的克隆限制為 300 個。此選項移除該上限，讓您可以建立任意數量的克隆。可以在[編輯器設定](/editor/settings)中啟用，或透過 [`clones` URL 引數](/advanced/url-parameters)（`clones=1000`）設定明確上限。

::::caution
有些專案依賴 Scratch 在超過限制後拒絕建立更多克隆。當限制被移除時，這些專案可能會出現異常。建立非常大量的克隆也會使專案變慢或耗盡記憶體。
::::
