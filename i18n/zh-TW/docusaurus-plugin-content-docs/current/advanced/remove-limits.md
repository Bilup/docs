# 移除雜項限制

此選項解除了若干小而零散的 Scratch 限制，這些限制沒有大到需要各自設定。可以在[編輯器設定](/editor/settings)或透過 [`limitless` URL 引數](/advanced/url-parameters) 啟用。

啟用後：

- 音調音效範圍從 360 增加到 1000。
- 設定或更改音效或音量的積木會立即執行，而不是讓指令碼暫停一幀。
- 畫筆最小尺寸從 1 降至 0，最大尺寸變為無限制（原來是 1200）。
- 滑鼠 X 和 Y 不再四捨五入，在高解析度或全屏下很有用。
- 移除音樂擴充功能同時 30 個鼓點和音符的限制。

此列表會不斷增長。
